# Photoboo Photobooth

A zero-install browser photobooth app. Open `index.html` directly in a browser, allow camera access, and capture a four-frame photo strip.

## Features

- Live camera preview with a demo fallback
- Camera flip and shutter sound controls
- Clean, Golden, Silver, and Pop moods
- Four-frame photo strip
- Lavender, night, and sky strip designs
- Cartoon stickers and custom strip text
- Downloadable combined strip image
- Responsive desktop and mobile layout

Camera permissions may be more reliable when served from `localhost` or a secure origin.
